Sentiment Studio API

Local Flask endpoints. Run .venv/bin/python app.py and use http://127.0.0.1:5050.

GET/

Open the sentiment analysis page.

GET/health

Check that the Flask server is running. Returns {"status":"ok"}.

POST/analyze

Send JSON with a non-empty text string:

{"text":"I loved this movie."}

Example response:

{"choice":"positive","score":1.9,"noul":0.95}

choice is positive, negative, or neutral. score runs from 0 (negative) through 1 (neutral) to 2 (positive). noul runs from 0 to 1 and estimates whether the text expresses positive sentiment. Values are local model estimates.

Try it from a terminal:

curl -X POST http://127.0.0.1:5050/analyze \
  -H 'Content-Type: application/json' \
  -d '{"text":"I loved this movie."}'

Errors: 400 for missing or invalid text; 502 when Ollama is unavailable or returns an invalid answer.
