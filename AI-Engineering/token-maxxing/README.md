# token-maxxing

> a chrome extension tools built with Vite + React, and Manifest v3

## Prompt compressor API

This separate FastAPI service compresses prompts with Microsoft's local LLMLingua-2 XLM-RoBERTa MeetingBank model, then sends the shorter prompt to Ollama for an answer. Install the sprint-level Python environment from the root README. The compressor model uses the normal Hugging Face cache. Make sure Ollama is running with `gemma4:e2b-mlx` available (or set `OLLAMA_MODEL` to another installed model), then run `../../.venv/bin/uvicorn compressor:app --host 127.0.0.1 --port 8000` from this directory.

Send `POST http://127.0.0.1:8000/compress` with JSON such as `{"prompt":"Please explain this topic in a concise way."}` to get `compressed_prompt`. The extension popup calls this endpoint and displays the compressed text as its echo. Send the same JSON to `/chat` to get both `compressed_prompt` and an Ollama `answer`.

## Installing

1. Check if your `Node.js` version is >= **14**.
2. Change or configurate the name of your extension on `src/manifest`.
3. Run `npm install` to install the dependencies.

## Develop in Chrome

1. Run `npm install` (once), then `npm run dev` from this folder. Leave the terminal running.
2. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
3. Click **Load unpacked** and select this project's `build` folder (the folder containing `manifest.json`).
4. Pin the extension to open its popup, or open a new tab to see the new-tab page. Changes to the source are served by Vite; if a manifest or background change does not appear, click the extension's **Reload** button at `chrome://extensions`.

For a build that works without the dev server, run `npm run build` and load the same `build` folder. Vite's dev port is chosen at startup and may vary when another project is already using the default port.

## Packing

After the development of your extension run the command

```shell
$ npm run build
```

Now, the content of `build` folder will be the extension ready to be submitted to the Chrome Web Store. Just take a look at the [official guide](https://developer.chrome.com/webstore/publish) to more infos about publishing.
